Before a resultless abort it writes a bundle manifest plus `tracked.patch` (`git diff --binary`), `staged.patch` (`git diff --binary --cached <base revision>`), and a NUL-delimited untracked manifest with a content archive for every `git ls-files --others --exclude-standard -z` path. Its workspace fingerprint is SHA-256 of canonical bundle metadata containing the base revision, each relative path, member kind, and member-content SHA-256. A missing, unreadable, or unarchived enumerated untracked path makes preservation fail; it is never recorded as a successful bundle.
